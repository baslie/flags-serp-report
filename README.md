# Конкуренты в нише флагов и печати на ткани: Москва, Яндекс

Исследование SEO-конкурентов. **Открыть:** https://roman-purtow.ru/flags-serp-report/

- **Итерация 2 (вверху отчёта):** из чего состоит страница, которая ранжируется: блоки, объём, коммерческие элементы, разметка, отличия топ-3 от позиций 7–10, шаблоны для генератора SEO-страниц.
- **Итерация 1 (архив ниже):** срез выдачи и собранные страницы конкурентов.

- Охват: 24 поисковых запроса в 6 тематических группах: заказ, виды флагов, печать, материалы, обработка, смежные услуги.
- Источник: первая страница органической выдачи Яндекса, регион Москва (`lr=213`). Реклама, колдунщики и агрегаторы в разбор не входят.
- Для каждой найденной страницы конкурента собраны Title, Description, H1–H3, секции, число слов, внутренние ссылки, разметка JSON-LD и миниатюра скриншота.

## Данные

| Файл | Содержимое |
|---|---|
| `data/serp.csv` | все позиции: тема, запрос, позиция, URL, домен, статус сбора |
| `data/pages.csv`, `data/pages.jsonl` | одна строка на страницу конкурента |
| `data/domains.csv` | сводка по доменам: охват запросов и тем, средняя и лучшая позиция |
| `data/page_spec.json` | шаблоны страниц для генератора: блоки, уровни, целевые диапазоны |
| `data/aggregates.json`, `data/tables.md` | агрегаты анализа страниц по позициям, классам запросов, темам и лидерам |

Позиции отражают выдачу на момент снятия и со временем меняются.
